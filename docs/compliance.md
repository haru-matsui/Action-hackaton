# Проверка PM Radar по кейсу 1

Дата: 27 сентября 2026. Источник: все четыре страницы «Уфа_Кейс_1.pdf».
Проверены исходники, маршруты API и автоматические сценарии. Это проверка
текущего MVP; заключения о полном соответствии и готовности к промышленной
эксплуатации до закрытия отмеченных ниже пунктов нет.

## Требования задания

| Требование | Состояние | Проверка / замечание |
|---|---|---|
| Создать проект, указать название и срок | Реализовано | Форма и POST /api/projects; пустой проект корректен, срок в рабочих днях |
| Добавить задачу, срок, ответственного и статус | Реализовано | Диалог задачи, предпросмотр и сохранение через /impact |
| Зависимости и последовательность работ | Реализовано | Выбор предшественников, граф, таблица, линия времени; циклы отклоняются до записи |
| Менять сроки, статус и ответственного | Реализовано | /impact; смена исполнителя сама по себе не обещает ускорения |
| Добавлять, удалять и редактировать задачи и связи | Реализовано | CRUD, обновление зависимостей при удалении, защита устаревшей формы |
| Показывать затронутые последующие задачи | Частично | При редактировании есть сравнение; после удаления пока только пересчёт плана без карточки «до/после» |

| Показывать наиболее критичные задачи | Реализовано | Все равные критические ветки, включая их связи; отдельная цепочка не выдаётся за полный набор |
| Показывать необходимость вмешательства | Реализовано | requires_action, предупреждения и рекомендации; учитываются все критические ветки |
| Представление сроков, состояния, зависимостей, проблем | Реализовано | Показатели, линия времени, таблица, граф, радар |
| Демонстрация: минимум 8 задач | Реализовано | 10 задач, 5 ответственных, несколько зависимостей, выполненные и незавершённые задачи |
| Демонстрация изменения и последствий | Проверено | Backend 10 → 17 дней: прогноз 29 → 36, превышение дедлайна 30 на 6 дней; предпросмотр не пишет базу |
| Дополнительная встроенная функция | Реализовано | Песочница с несколькими изменениями, объяснения ассистента, радар и отчёт |

## Согласованное поведение

Вкладки над планом — единственное переключение его представлений. Слева остаются
выбор/создание проекта, прогресс и недоступные разделы «Команда», «Файлы»,
«Интеграции» — только названия и иконки, без отметок. Функции этих разделов
не реализуются в MVP.

Общий редактор существующего проекта и отдельный предпросмотр удаления не добавляются:
пользователь оставил их за рамками MVP. После удаления план пересчитывается.
Срок и название задаются при создании. Ограничение удаления в таблице требований
сохранено явно; оно не скрывается формальным заявлением о полном соответствии.

Начатые и завершённые задачи остаются неподвижными в песочнице по решению
пользователя. Для начатых задач срок меняется через обычную форму. При попытке
перетащить такую задачу выводится пояснение ограничения.

Все одинаково критичные ветки выделяются. Сценарий отпуска и условные +50%
удалены по решению пользователя; неподдерживаемый вопрос не вызывает модель
и не запускает расчёт.

## Что исправлено при этой проверке

- При переходе из линии времени в таблицу/граф песочница закрывается. Если
  сценарий изменён, пользователь подтверждает сброс; отмена оставляет сценарий.
- Поздние ответы сценария игнорируются после выхода; повторные клики не
  открывают несколько подтверждений одновременно.
- Ассистент открывается кнопкой сверху справа и сворачивается крестиком.
  Без него основная область занимает всю ширину; вход в песочницу открывает панель.
- Убрана отдельная кнопка ассистента из боковой навигации.
- Циклический проект больше не сохраняется при создании до проверки графа.
- Проверяются типы, диапазоны сроков, повторяющиеся идентификаторы,
  отсутствующие предшественники и зависимости задачи от самой себя.
- Устаревшие формы не перезаписывают изменения другого окна.
- Короткие и нулевые задачи при разбиении сохраняют суммарную длительность.
- Устаревший результат генерации подзадач не применяется к изменённой форме.
- Ошибка загрузки другого проекта восстанавливает выбор текущего проекта.
- Сетевые ошибки показываются понятным текстом. Радар не обещает запас до
  незаданного дедлайна и не называет любую задержку нарушением срока.

## Проверенные части

| Часть | Как проверялась |
|---|---|
| Создание, изменение, завершение, удаление проекта/задач | Изолированная временная база, API-тесты полного цикла |
| Расчёты, зависимости, резерв, демонстрация | Детерминированные сценарии API и сравнение результатов |
| Хранение | Сравнение байтов базы при ошибках/предпросмотре, атомарная запись, проверки версий |
| Песочница | Несколько правок, быстрые действия, запоздавшие ответы, сброс, конфликт, сохранение без ожидания ИИ |
| Навигация и сворачивание панели | Тесты контроллера, состояния вкладок, фокуса и отмены перехода |
| ИИ-адаптер | Контракт JSON, резервные ответы, таймауты, недопустимые числа, отсутствие ключа в выдаче |
| Отчёт, объяснения, радар, чек-лист | Тесты API и чтение кода; ИИ заменён контролируемыми ответами в тестах |
| Безопасный вывод текста | Названия, имена и ответы экранируются перед вставкой в HTML |
| Docker | Пересборка, запуск, HTTP-проверка актуальных ресурсов и /api/health |

36 серверных тестов и 13 тестов JavaScript проходят. Проверки не обращаются
к платному ИИ и не изменяют пользовательские проекты.
Визуальная проверка настоящим браузером в этой сессии не выполнена:
управление браузером ранее заблокировано политикой инструмента. Автотесты
не подтверждают отсутствие всех визуальных дефектов на каждом размере экрана.

## Границы требований

PDF требует работающий MVP, а не полноценную корпоративную систему.
Календарные даты, авторизация, роли доступа, бюджет, реальные отпуска,
интеграции и учёт рабочего календаря явно не требуются. Они не добавляются.
Расчёт использует рабочие дни относительно текущего плана; завершённые задачи
имеют нулевую оставшуюся длительность. Загрузка сотрудников — количество
незавершённых задач всего проекта, без знания навыков и доступности.
Проверка чисел ответа ИИ ограничивает ошибки, но не доказывает правильность
всех причинно-следственных утверждений модели.


### Согласованное дополнение — календарные сроки

28 сентября 2026 добавлены дата начала, фиксированный календарный дедлайн и текущий
рабочий день. Старые проекты получают даты только по выбору пользователя.
Гант, таблица, песочница, отчёт и факты ИИ используют единый расчёт пн–пт.
Праздничный календарь, фактические даты задач и табели не добавляются.
